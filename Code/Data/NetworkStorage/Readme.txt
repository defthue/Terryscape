================================================================================
  Network Storage — Auto-Generated Code
================================================================================

  DO NOT EDIT the autoGenerated_*.cs files in this folder.
  They are regenerated every time you push from the Sync Tool.

  HOW TO MAKE CHANGES
  —————————-

  1. Edit the source JSON files in your project's Editor/Network Storage/ folder:

       collections/*.json  — Collection schemas (field names, types, constraints)
       endpoints/*.json    — Server-side endpoint pipelines (validation, writes)
       workflows/*.json    — Reusable validation / computation workflows
       config/             — API credentials and project settings

  2. Push changes to the backend and regenerate this folder:

       Editor → Network Storage → Sync Tool → Push All

     Or regenerate code without pushing:

       Editor → Network Storage → Generate Code

  ARCHITECTURE
  ——————

  Editor/Network Storage/       — Full backend configuration. Stored in your
                                  project repository for syncing with the
                                  Network Storage API. Contains endpoint logic,
                                  collection schemas, validation workflows, and
                                  secret keys. Editor-only — this folder is
                                  excluded from the published game.

  Code/Data/NetworkStorage/     — Game bundle code. Auto-generated typed
                                  references to your backend schema. Ships with
                                  the published game so runtime code can use
                                  constants and types instead of magic strings.
                                  Read-only — regenerated on every sync.

  USAGE EXAMPLES
  ———————

  // Configure the client at startup (auto-generated credentials)
  NSConfig.EnsureConfigured();

  // Call endpoints with typed slugs instead of magic strings
  var data = await NetworkStorage.CallEndpoint( NSEndpoints.LoadPlayer );

  // Reference input fields by name
  var result = await NetworkStorage.CallEndpoint( NSEndpoints.SellOre,
      new { ore_id = "moon_ore", kg = 10.0, faction_id = "avery_exchange" } );

  // Access collection field paths for queries
  string field = PlayerDataSchema.Ores.MoonOre;  // "ores.moon_ore"

  // Read game constants
  int startingQC = GameValuesSchema.Progression.StartingCurrency_Value;  // 500
